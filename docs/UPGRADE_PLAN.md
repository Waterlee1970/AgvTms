**MIP数学模型核心：**

```
最小化:
  Z = w1 * Makespan + w2 * ∑(TravelDistance) + w3 * ∑(Tardiness) + w4 * ∑(IdleTime)

约束:
  1. 每个任务恰好分配给一台AGV:    ∑_k x_ik = 1  (∀i)
  2. AGV容量限制:                   ∑_i x_ik ≤ C_k  (∀k)
  3. 任务优先级约束:                start_i + duration_i ≤ start_j  (i→j)
  4. AGV同时执行任务数限制:        在同一时刻, AGV只能执行一个任务
  5. 电池约束:                     当前电量 + 充电 ≥ 任务消耗
  6. 时间窗约束:                    到达时间 ∈ [earliest, latest]
  7. 输送线接口约束:               输送线任务完成 → AGV可接取
```

### 3.6 Week 6-8: 强化学习 + 性能验证

#### RL调度智能体

```
状态空间:
  - AGV位置、电量、任务负载
  - 任务池状态(数量、优先级、截止时间)
  - 路网负载、拥堵区域
  - 输送线缓冲区状态

动作空间:
  - 任务分配: 将任务T_i分配给AGV_j
  - 路径选择: 从K条备选路径中选择
  - 重调度触发: 何时触发全局重调度

奖励函数:
  R = -w1*makespan - w2*∑delay - w3*∑energy + w4*task_completed

算法选择:
  - Phase 1: DQN (离散动作, 易于验证)
  - Phase 2: PPO (连续控制, 更精细)
  - 训练: Gym仿真环境 + 课程学习
```
