## 二、基础概念快速入门

### 2.1 什么是AGV？

**AGV** = Automated Guided Vehicle (自动导引运输车)

简单理解：**不需要人工驾驶的智能搬运机器人**

```
传统方式 vs AGV自动化:
┌──────────────┐     ┌──────────────┐
│  工人+叉车    │     │    AGV       │
│              │     │              │
│  👨‍💼 → 🚜 → 📦│     │  🤖自动行驶→📦│
│  体力劳动    │     │  智能调度     │
│  效率依赖人  │     │  24小时工作   │
│  有安全风险  │     │  安全避障     │
└──────────────┘     └──────────────┘
```

**AgvTms支持的车型类型**：

| 外观示意 | 类型名称 | 典型用途 | 载重能力 |
|---------|---------|---------|---------|
| 🛒 | 标准搬运AGV | 小件物料转运 | ~100kg |
| 🏗️ | 叉车AGV | 托盘搬运堆垛 | ~1000kg |
| 📦 | 潜伏顶升AGV | 料架底部搬运 | ~300kg |
| ⬆️ | 顶升AGV | 辊筒对接输送线 | ~500kg |
| 📬 | 分拣AGV | 快递包裹分拣 | ~50kg (高速) |
| 🚛 | 牵引AGV | 重载牵引拖车 | ~2000kg |

### 2.2 核心术语解释

#### 任务 (Task)
一次完整的**物料搬运需求**：
```
任务示例:
  从: 仓库A区 (取货点)
  到: 加工站B (卸货点)
  运送: 50kg 电子元器件
  要求: 10分钟内送达
```

**任务的生命周期**：

```
[待分配] ──→ [已分配] ──→ [执行中] ──→ [已完成]
  PENDING     ASSIGNED    IN_PROGRESS   COMPLETED
                          ↘ 失败 → FAILED
                          ↘ 取消 → CANCELLED
```

#### 节点 (Node)
地图上的**关键位置点**：

| 节点类型 | 图标 | 说明 | 示例 |
|---------|------|------|------|
| 取货点 | 📥 | AGV在此处装载物料 | 仓库出口 |
| 卸货点 | 📤 | AGV在此处卸载物料 | 生产线入口 |
| 充电桩 | ⚡ | AGV电量低时自动前往 | 充电房 |
| 十字路口 | ✚ | 路径交叉点 | 走廊转角 |
| 通道点 | · | 行驶路径的中间点 | 直行路段 |

#### 调度 (Dispatch/Scheduling)
系统根据**当前情况**自动决定：
1. **哪辆车**去执行任务（选择最合适的AGV）
2. **走哪条路**（规划最优路径）
3. **什么时候出发**（避免拥堵碰撞）

```
调度前: 5个任务等待, 8辆AGV空闲
  ↓ [点击"开始调度"]
调度后:
  AGV-01 → 任务A (距离最近)
  AGV-02 → 任务B (车型匹配)
  AGV-03 → 任务C (电量充足)
  ...
  所有任务都有明确的执行计划!
```

## 三、任务操作指南

### 3.1 创建单个任务（标准流程）

#### Step 1: 进入任务管理页面

1. 点击顶部菜单 **「任务管理」**
2. 确保处于 **「待处理」** 标签页

#### Step 2: 点击「新建任务」按钮

在页面右上角找到绿色的 **「+ 新建任务」** 按钮，点击后弹出对话框：

```

│                                                 │

│                                                 │
│  *取货地点:  [请选择节点 ▾]  ← 点击下拉框选择    │
│  *卸货地点:  [请选择节点 ▾]                      │
│                                                 │
│  ── 物料信息 (选填) ─────────────────           │
│                                                 │

│                                                 │
│  [ 取消 ]                    [ 创建任务 ]        │
└─────────────────────────────────────────────────┘
```

#### Step 3: 填写必要信息

**必填项**（标记*号的）:

| 字段 | 如何填写 | 提示 |
|-----|---------|------|
| **取货地点** | 点击下拉框，在弹出的地图上点击取货点 | 或输入节点ID如 `warehouse_A` |
| **卸货地点** | 同上，选择目的地节点 | - |

**选填项**（建议填写以提高调度质量）:

| 字段 | 为什么重要 | 示例值 |
|-----|----------|--------|
| **物料重量** | 系统会自动排除载重不足的AGV | `50` (公斤) |
| **优先级** | 紧急任务会优先分配 | `0-255` (数值越大越优先) |
| **截止时间** | 超时未完成会触发告警 | `12:00` (今天中午) |
| **指定车型** | 特殊货物需特殊车辆 | `forklift` (需叉车) |

#### Step 4: 提交并查看结果

1. 点击 **「创建任务」** 按钮
2. 成功后会显示提示：✅ "任务 T-20260705-001 已创建"
3. 任务会立即出现在下方的任务列表中

### 3.2 快速创建任务（简化版）

对于**重复性高的常规搬运**，可以使用快捷方式：

#### 方式一：从地图直接创建

1. 进入 **「车队监控」** 页面
2. 在地图上 **右键点击取货点**
3. 选择 **「从此处创建任务...」**
4. 再 **右键点击目标点** 作为卸货地
5. 弹出预填好的对话框，确认即可

#### 方式二：使用模板

如果每天都要执行相同的搬运路线：

1. 在 **「任务管理」** 页面点击 **「任务模板」** 标签
2. 点击 **「新建模板」**
3. 填写固定的路径信息，保存为模板（如 `"仓库→产线-早班"`）

之后创建任务时只需：
1. 选择模板 → 2. 填写数量/优先级 → 3. 提交

**时间节省: 30秒 → 5秒！**

### 3.3 批量导入任务（适用于大量订单）

当有几十上百个任务需要一次性创建时（如电商波次拣货）：

#### Step 1: 下载模板文件

在 **「任务管理」** → **「批量操作」** → **「下载导入模板」**

下载得到Excel文件 `task_import_template.xlsx`

#### Step 2: 填写任务数据

打开Excel文件，按格式填写：

| A列-取货点 | B列-卸货点 | C列-重量(kg) | D列-优先级 | E列-截止时间 |
|-----------|-----------|-------------|-----------|------------|
| warehouse_A | line_01 | 20 | 5 | 2026/7/5 10:00 |
| warehouse_B | line_02 | 35 | 8 | 2026/7/5 10:15 |
| warehouse_A | line_01 | 18 | 5 | 2026/7/5 10:30 |
| ... | ... | ... | ... | ... |

**注意事项**：
- ❌ 不要修改表头（第一行）
- ❌ 不要删除空行中间的数据
- ✅ 节点名称必须与系统中一致
- ✅ 时间格式必须统一

#### Step 3: 上传并导入

1. 回到 **「批量操作」** 页面
2. 点击 **「选择文件」** → 选择填好的Excel
3. 点击 **「预览导入」** → 检查数据是否正确
4. 点击 **「确认导入」**

系统会显示结果：
```
导入完成！
✅ 成功: 95 条任务
❌ 失败: 5 条 (原因见下方详情)
   - 第3行: 节点 "warehouse_X" 不存在
   - 第7行: 重量格式错误 (非数字)
   ...
```

### 3.5 取消/修改任务

#### 取消任务

**适用场景**: 
- 订单被客户取消
- 生产计划变更
- 发现任务创建错误

**操作步骤**:
1. 在任务列表找到目标任务
2. 点击 **「取消」** 按钮
3. 在确认对话框中选择 **取消原因**:
   - ☐ 订单取消
   - ☐ 计划变更
   - ☐ 创建错误
   - ☐ 其他（请填写）：______
4. 点击 **「确认取消」**

**注意**：
- ⚠️ 如果任务正在执行中，系统会先向AGV发送停止指令
- ⚠️ 已经完成的部分无法撤销（如AGV已经取货）

#### 修改任务（仅限待分配状态）

**适用场景**: 
- 目的地写错了
- 优先级需要调整
- 物料信息补充

**操作步骤**:
1. 找到状态为 **「待分配」** 的任务
2. 点击 **「编辑」** 按钮
3. 修改需要更改的字段
4. 保存

**注意**：
- ❌ 已分配或正在执行的任务**不能修改**（只能取消重建）
- ✅ 可以修改的字段：优先级、截止时间、物料信息、指定车型
- ❌ 不能修改的字段：取货点、卸货点、任务类型

### 4.2 车辆状态解读

| 状态图标 | 含义 | 说明 | 是否可接受新任务 |
|---------|------|------|----------------|
| 🟢 ● | **移动中** | 正在执行任务，前往某处 | ❌ 暂时不可 |
| ⚪ ○ | **空闲** | 无任务，等待分配 | ✅ 可立即分配 |
| 🔋 ⊙ | **充电中** | 电量低，自动回充或手动充电中 | ❌ 充电完成后可用 |
| ⏳ ◑ | **等待中** | 被分配任务但尚未出发（可能在排队） | ❌ 已有任务 |
| 🔴 ✕ | **故障/离线** | 设备异常或通信中断 | ❌ 需排查修复 |
| 🟡 ⚠ | **警告** | 存在潜在问题（如电量低） | ⚠️ 可分配但不建议 |

### 4.3 远程控制车辆

> ⚠️ **重要提示**: 远程控制功能需要相应权限，普通操作员可能只能查看。

#### 急停 (Emergency Stop)

**何时使用**: 发现AGV可能造成安全事故（如即将撞人或障碍物）

**操作方法**:
1. 在车辆列表或地图上 **点击目标车辆**
2. 在弹出卡片中找到红色的 **「紧急停车」** 按钮
3. **再次确认**（防止误触）:
   ```
   ⚠️ 确认对 AGV-01 执行急停操作？
   
   急停后车辆将立即制动，可能需要人工复位才能恢复。
   
   [取消]  [确认急停]
   ```
4. 车辆收到指令后会立即停止，状态变为 **「已锁定」**

**急停后的恢复**:
1. 排除现场安全隐患
2. 在车辆旁按下物理急停按钮（旋转解锁）
3. 或在系统中点击 **「解除锁定」**

#### 手动派遣 (Manual Dispatch)

强制让特定车辆前往某个位置（不经过正常调度）：

**适用场景**:
- 需要某辆车去维修点检修
- 临时需要车辆去某处应急
- 测试车辆运动性能

**操作步骤**:
1. 选择空闲状态的车辆（○空闲）
2. 点击 **「手动派遣」**
3. 选择目标位置节点
4. 确认

```
手动派遣 AGV-04
目标位置: [维修间 ▾]
原因: [例行保养 ▾]
备注: [检查轮胎磨损情况    ]

[取消]  [确认派遣]
```

#### 强制回充 (Force Charge)

手动命令车辆返回充电桩：

**触发条件** (任一满足):
- 电量 < 15% 且无紧急任务时 **系统自动触发**
- 操作员判断接下来长时间闲置 **手动触发**

**操作方法**:
1. 选择目标车辆
2. 点击 **「强制回充」**
3. 系统自动规划到最近可用充电桩的最短路径

## 五、异常处理速查表

### 5.1 常见问题及解决方案

#### 问题一：AGV显示"离线"

```
现象: 
  车辆列表显示 AGV-XX 状态为 🔴 离线
  地图上该车辆图标消失或变灰
  
可能原因 (按概率排序):
  1. WiFi信号丢失 (70%)
  2. AGV电源耗尽关机 (15%)
  3. AGV发生故障报错 (10%)
  4. 系统网络问题 (5%)

解决步骤:
  Step 1: 确认现场AGV是否还在运行
          → 如果完全停机: 检查电源/电池
          → 如果还在运行但不动: 可能是网络问题
  
  Step 2: 检查WiFi/AP状态
          → AGV所在区域的AP是否正常工作？
          → 用手机测试同一位置的网络信号强度
          
  Step 3: 尝试重启AGV
          → 长按AGV机身电源键10秒关机
          → 再按3秒开机
          → 观察系统是否重新识别
          
  Step 4: 如果以上都无效
          → 联系设备维修人员
          → 在系统备注栏记录问题现象
```

#### 问题二：任务一直显示"待分配"

```
现象:
  创建任务超过5分钟仍显示 ◉ 待分配状态
  没有任何车辆被指派

可能原因:
  1. 所有车辆都在忙/充电/故障 (最常见)
  2. 没有符合条件的车辆 (如载重不够)
  3. 目标区域被封锁/维护中
  4. 调度引擎异常

解决步骤:
  Step 1: 查看车队总览
          → 是否所有在线车辆都是 ●移动中？
          → 如果是: 属于正常排队等待
          
  Step 2: 检查任务约束条件
          → 该任务要求的载重/车型是否有车能满足？
          → 例如: 要求叉车AGV但只有潜伏式可用
          
  Step 3: 手动触发调度
          → 进入「调度中心」
          → 点击「立即调度」按钮
          → 观察是否有错误提示
          
  Step 4: 调整任务参数
          → 降低优先级要求
          → 放宽车型限制 (改为"自动匹配")
```

#### 问题三：AGV卡在某个位置不动

```
现象:
  AGV显示 ●移动中 但实际位置长时间不变
  任务进度条停在某个百分比

可能原因:
  1. 前方有障碍物 (其他AGV/人员/货物)
  2. 路径上的门/电梯未开启
  3. AGV自身传感器误判 (假阳性障碍物)
  4. 通信延迟导致指令丢失

解决步骤 (按顺序尝试):
  
  Step 1: 远程观察 (通过摄像头/现场确认)
          → 前方是否真的有障碍物？
          → 清除障碍物后看AGV是否恢复
          
  Step 2: 稍等片刻 (1-2分钟)
          → 可能是临时阻塞, 系统会自动重新规划路径
          
  Step 3: 手动重试该任务
          → 在任务列表点击「重试」
          → 系统会重新计算新的路径
          
  Step 4: 最后手段 - 取消任务并重新创建
          → 先「取消」原任务
          → 等1分钟让AGV回到空闲
          → 创建新任务
```

## 六、调度策略配置 (进阶)

> 本章面向**调度员**角色，普通操作员可跳过。

### 6.1 理解调度逻辑

系统如何决定哪个AGV去执行哪个任务？

```
用户创建任务
    ↓
[调度引擎启动]
    ↓
考虑因素:
  ├── 距离: 哪辆车离取货点最近?
  ├── 能力: 这辆车能搬这么重的货吗?
  ├── 电量: 够不够跑完这趟再回来?
  ├── 状态: 是不是正在忙/充电/故障?
  ├── 路径: 去的路上会不会堵车?
  └── 优先级: 这个任务是不是很紧急?
    ↓
综合评分, 选出最优解
    ↓
输出: 任务X → 分配给AGV-Y → 经由路径Z
```

### 6.2 常用调度策略预设

系统内置了几种常用策略，可根据生产模式切换：

| 策略名称 | 适用场景 | 优化目标 | 典型效果 |
|---------|---------|---------|---------|
| **均衡模式 (默认)** | 一般生产环境 | 负载均匀分布 | 各车使用率接近 |
| **速度优先** | 紧急订单多 | 最快完成任务 | 个别车很忙, 其他较闲 |
| **节能模式** | 夜班/低谷期 | 减少总行驶距离 | 任务稍慢但省电 |
| **先来先服务 (FCFS)** | 简单场景 | 按顺序公平分配 | 公平但效率一般 |

**切换调度策略**:

1. 进入 **「调度中心」** 页面
2. 在 **「策略配置」** 标签页
3. 下拉选择目标策略
4. 点击 **「应用并保存」**
5. 新策略将在下次调度时生效

```

│  调度策略配置                          [保存] │
├─────────────────────────────────────────────┤

│                                             │
│  可选策略:                                   │
│  ○ 均衡模式 - 适合大多数场景               │
│  ○ 速度优先 - 紧急任务优先响应             │
│  ○ 节能模式 - 减少空驶和能耗               │
│  ○ FCFS - 简单按序分配                     │
│  ○ 自定义 - 高级用户自行调参               │
```

### 6.3 高级参数调节 (自定义模式)

对于有经验的调度员，可以微调算法参数：

| 参数 | 默认值 | 含义 | 调大效果 | 调小效果 |
|------|-------|------|---------|---------|
| **距离权重** | 0.3 | 路径长度的重要性 | 偏好短途 | 不太在乎远近 |
| **负载权重** | 0.2 | 均匀分配的重要性 | 各车更均衡 | 允许忙闲不均 |
| **电量阈值** | 20% | 低于此值不派任务 | 更保守 (较早回充) | 更激进 (用到更低) |
| **超时限制(s)** | 25 | 单次调度最长计算时间 | 结果更好但更慢 | 快速出结果但可能非最优 |

**⚠️ 注意事项**:
- 修改参数前请 **记录当前值** (方便回滚)
- 建议 **一次只改一个参数** 并观察效果
- 生产高峰期 **不建议频繁调整**
- 不确定时使用 **默认值** 通常是最安全的

## 七、报表与数据分析

### 7.1 查看今日运营概况

**位置**: **「仪表盘」** 页面

展示的关键指标 (KPI):

| 指标名 | 含义 | 好的标准 | 异常警示 |
|-------|------|---------|---------|
| **任务完成率** | 成功完成任务 / 总任务 × 100% | >95% | <90% 需关注 |
| **平均等待时间** | 任务从创建到开始执行的间隔 | <3分钟 | >10分钟有问题 |
| **车辆利用率** | 有任务的车 / 总在线车 × 100% | 70%-90% | 太低=浪费, 太高=无弹性 |
| **总行驶里程** | 所有AGV今天跑了多少公里 | 取决于规模 | 突然增加可能是路径绕路 |
| **故障次数** | 出现异常报警的次数 | 越少越好 | 连续增多需检修 |

### 7.2 导出历史报表

**位置**: **「历史报表」** 页面

支持导出的报表类型:

| 报表 | 内容 | 用途 | 格式 |
|------|------|------|------|
| **任务明细表** | 每个任务的完整生命周期 | 追溯分析 | Excel/CSV |
| **车辆运行日志** | 每辆车的活动记录 | 绩效考核/维保计划 | PDF/Excel |
| **效率统计报告** | 按时段汇总的吞吐量数据 | 向管理层汇报 | PDF(PPT风格) |
| **能耗分析报告** | 电量消耗统计 | 成本核算/节能评估 | Excel |

**导出步骤**:
1. 选择报表类型
2. 设置时间范围 (今日/本周/本月/自定义)
3. 可选: 过滤特定车辆或区域
4. 点击 **「生成报表」**
5. 等待几秒钟 (大数据量时可能需要1-2分钟)
6. 点击 **「下载」** 保存到本地

### 7.3 常用数据解读案例

**案例一: 发现上午10点经常堵车**

```
数据表现:
  - 9:00-10:00 平均等待时间: 2分钟 (正常)
  - 10:00-11:00 平均等待时间: 12分钟 (异常!)
  - 11:00后恢复正常

可能原因:
  - 多个产线同时在10点换班/交接物料
  - 上午集中到货导致仓库出货压力大
  - 某个瓶颈路段在该时间段流量过大

改进建议:
  - 错峰: 将部分任务提前到9:30或推迟到10:30
  - 增加该时段的可用车辆 (从其他区域临时调用)
  - 优化瓶颈路段的路径规划
```

**案例二: 某辆车效率明显偏低**

```
数据表现:
  - AGV-07 日均完成任务: 8个 (车队平均: 18个)
  - AGV-07 故障次数: 3次/周 (车队平均: 0.5次)
  - AGV-07 经常出现在充电状态

可能原因:
  - 电池老化, 容量衰减, 需频繁充电
  - 机械部件老化, 速度变慢
  - 该车常被分配到远距离任务 (路径配置问题)
  - 所在区域WiFi信号差, 经常掉线重连

改进建议:
  - 安排电池检测/更换
  - 全面机械保养
  - 检查该车的工作区域范围是否合理
```

### 8.2 地图编辑入门

**位置**: **「地图配置」** 页面

#### 添加新节点 (取货/卸货点)

1. 切换到 **「编辑模式」** (右上角开关)
2. 在地图上 **双击** 要添加节点的位置
3. 在弹出框中填写:
   - 节点名称: `新取货点_C区`
   - 节点类型: `取货点`
   - 其他属性 (可选)
4. 点击保存

#### 修改路径 (边)

1. 在编辑模式下 **点击现有的路径线条**
2. 可以:
   - **拖动端点** 改变连接的节点
   - **修改权重** (通行时间或距离)
   - **删除路径** (不再允许通行)
3. 保存更改

#### 封锁区域

当某个区域需要临时禁止AGV进入 (如施工/堆货):

1. 在编辑模式下选择 **「绘制区域」** 工具
2. 在地图上圈出要封锁的范围
3. 选择封锁原因和预计持续时间
4. 应用

**效果**: 调度时会自动避开该区域的所有路径

### 8.3 数据备份与恢复

#### 自动备份 (推荐)

系统默认配置了 **每日凌晨自动备份**:
- 备份内容: 数据库完整快照 + 当日日志文件
- 保留期限: 最近30天的备份
- 存储位置: `/data/agvtms/backups/` (可在配置中修改)

#### 手动备份

1. **「系统设置」** → **「数据管理」**
2. 点击 **「立即备份」**
3. 等待完成 (通常1-5分钟, 取决于数据量)
4. 下载备份文件到本地 (额外保险)

#### 恢复备份

**⚠️ 警告**: 恢复操作会**覆盖当前数据**！

1. 确认所有操作员都已退出系统
2. **「数据管理」** → **「备份历史」**
3. 选择要恢复的时间点
4. 点击 **「恢复此备份」**
5. 二次确认 (输入管理员密码)
6. 等待恢复完成并重启服务

## 十、常见问题 FAQ

### Q1: 忘记密码怎么办?

联系您的管理员重置密码。管理员可以在「用户管理」→「重置密码」为您生成新的临时密码,首次登录后请及时修改。

### Q2: 系统提示"会话过期"怎么办?

这是安全机制,长时间无操作后会自动登出。只需重新输入密码登录即可。建议勾选「记住我」选项可以延长至7天免登录。

### Q3: 可以同时在两台电脑上登录吗?

可以。同一个账号允许多设备同时登录,操作会实时同步。但如果发现异常登录行为,管理员可以强制踢出会话。

### Q4: 创建任务后发现填错了怎么办?

- 如果还是 **「待分配」** 状态: 可以直接编辑修改
- 如果已经 **「执行中」**: 需要先取消,再重新创建正确的任务

### Q5: 为什么有些任务一直不被执行?

请依次检查:
1. 是否有在线且空闲的车辆?
2. 任务的要求 (载重/车型) 是否有车能满足?
3. 取货点和卸货点的路径是否畅通 (未被封锁)?
4. 查看是否存在未处理的报警阻碍了调度

### Q6: AGV没电了会怎么办?

系统会在电量降到 **20%** 时自动停止给该车分配新任务,并在当前任务完成后自动安排回充。如果电量过低 (**<10%**),会立即中止当前任务并紧急回充。

您也可以随时手动点击「强制回充」。

### Q7: 如何知道系统是否有更新?

管理员可以在「系统设置」→「关于」页面查看版本号。如果有新版本发布,系统会在此处显示更新提示。建议关注官方公告频道获取更新说明。

### Q8: 遇到不确定的操作应该怎么做?

- ❌ **不要盲目点击**未知功能的按钮
- ✅ 按 **F1** 或点击 **「帮助」** 图标 查看上下文帮助
- ✅ 联系您的上级或经验丰富的同事
- ✅ 查阅本手册的相关章节
- ✅ 在工作时间拨打技术支持热线
