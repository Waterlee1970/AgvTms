# AGV-TMS 项目里程碑发展与现状评估总览

> **生成时间**: 2026-06-20  
> **当前版本**: v1.8 (分支 `1.8`)  
> **项目性质**: AGV柔性物流调度系统 — 研究型+工程原型级 → 向工业可用过渡

---

## 一、项目定位与愿景

### 1.1 一句话定义
**AGV-TMS** 是一个面向制造产线场景的 **AGV + 输送线混合调度系统**，以"算法丰富度超越商业竞品"为核心竞争力，目标对标海康威视RCS-2000 V4.0。

### 1.2 技术栈全景
| 层 | 技术选型 | 说明 |
|---|---------|------|
| 前端 | React 18 + TypeScript + Ant Design 5 + Zustand + Vite + Three.js/R3F | 11个功能页面 |
| 后端 | Python FastAPI + Pydantic v2 + uvicorn | 单体架构 |
| 存储 | PostgreSQL + Redis (asyncpg未安装时降级内存模式) | 持久化+缓存 |
| 算法 | NumPy/SciPy/NetworkX/OR-Tools | 11种核心算法模块 |
| 通信 | REST (80+端点) + WebSocket (2端点) | 实时+请求响应 |
| 部署 | Docker Compose | 单机容器化 |

```
│  PostgreSQL │ Redis │ (可选: asyncpg缺失时内存模式)  │
└─────────────────────────────────────────────────────┘
```

#### 关键瓶颈
| 瓶颈 | 影响 | 解决方案 | 优先级 |
|------|------|---------|:------:|
| **Python GIL锁** | 无法真正并行处理多AGV调度 | 异步IO + 多进程Worker | P0 |
| **单体架构** | 无法横向扩展 | 微服务拆分(K8s) | P1 |
| **同步阻塞调用** | 大场景下API超时 | 全链路异步(async/await) | P0 |
| **无消息队列** | 事件积压导致延迟 | Kafka/RabbitMQ | P0 |
| **无时序存储** | 历史轨迹查询慢 | InfluxDB/TDengine | P1 |
