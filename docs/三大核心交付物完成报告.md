### 🏗️ 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                    HybridScheduler                           │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: 任务分派 (Dispatcher Integration)                  │
│    ├─ MIP优化分派 (CP-SAT, 大规模最优)                       │
│    ├─ 匈牙利算法 (O(n³), 中等规模快速)                        │
│    └─ 贪心就近 (fallback, 无依赖)                            │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 路径规划 (Router/ECBS Integration)                 │
│    ├─ 单agent: Theta* (任意角度, 平滑路径)                   │
│    ├─ 多agent: ECBS (Conflict-Based Search, ω=1.2)         │
│    └─ Fallback: BidirectionalAStar / SIPP                   │
├─────────────────────────────────────────────────────────────┤
│  Layer 3: 交通管制 (Traffic Control System)                  │
│    ├─ ResourceLockManager (死锁预防, O(1))                  │
│    └─ TrafficControlSystem (拥堵检测, 通行审批)              │
└─────────────────────────────────────────────────────────────┘
```

### 🎯 核心能力

#### 1. 智能模式切换 (`_auto_select_mode`)
```python
# 决策逻辑:
if n_agvs <= 3 → SINGLE_AGENT (Theta*, 低开销)
elif task_density > 70% → MULTI_AGENT (ECBS, 防碰撞)
else → SINGLE_AGENT
```

#### 2. 完整调度流水线 (`schedule_batch`)
```
Tasks + AGVs → [Phase 1: Dispatch] → Task-AGV分配
            → [Phase 2: Path Plan] → 无碰撞路径集合
            → [Phase 3: Traffic Control] → 锁资源 + 审批通行
            → [Phase 4: Build Result] → SchedulingResult
```

#### 3. 弹性降级机制
- **Theta* 失败** → 自动降级到 AStar
- **ECBS 超时** → 回退到单agent并行规划
- **Dispatcher 异常** → 使用 Greedy 兜底
- **任何层崩溃** → 终极降级: 纯 A*-only 模式

### API使用示例

```python
from app.algorithms.v2.core.hybrid_scheduler import create_hybrid_scheduler, SchedulerMode

# 创建调度器实例
scheduler = create_hybrid_scheduler(
    graph=my_pathgraph,
    traffic_manager=my_tcs,
    mode="auto",              # 自动选择策略
    ebs_omega=1.2,           # ECBS子最优边界
    default_dispatcher="hungarian"
)

# 场景1: 批量调度 (最常用)
tasks = [Task(...), ...]
agvs = [AgvState(...), ...]
result = await scheduler.schedule_batch(tasks, agvs)
print(f"调度完成: {len(result.paths)} 条路径, 耗时{result.scheduling_time_ms:.1f}ms")

# 场景2: 单任务紧急调度
urgent_path = await scheduler.schedule_single(task=emergency_task, agv=nearest_agv)

# 场景3: 动态重规划 (拥堵感知)
if result.congestion_level == "CRITICAL":
    reroute_result = await scheduler.reroute(task_ids=[...], reason="congestion")

# 查询统计
stats = scheduler.get_statistics()
print(f"总调度次数: {stats['total_schedules']}, "
      f"Theta*使用率: {stats['theta_star_usage_pct']:.1f}%")
```
