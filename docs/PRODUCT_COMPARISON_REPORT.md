# AGV-TMS 产品系统与同类产品对比分析报告

**报告日期**: 2026年6月15日  
**项目名称**: AgvTms - 混合调度柔性物流系统  
**对标产品**: 海康威视RCS、极智嘉RMS、海柔创新HAIQ、旷视河图、仙工智能SEER

## 一、执行摘要

本报告对 **AgvTms（AGV Transport Management System）** 与当前市场上主流的AGV/AMR调度管理系统进行了全方位对比分析。AgvTms是一个**研究型+工程原型级**混合调度系统，具备独特的**V1元启发式 + V2工业级优化引擎双版本架构**，集成了强化学习(DQN/PPO)、整数规划(MIP/CP-SAT)、三层协调器等先进算法。

**核心结论**: AgvTms在**算法丰富度**和**学术创新性**方面已达到或部分超越商业产品的水平，但在**工程成熟度、部署规模、可视化能力**等方面仍有差距。系统定位适合作为**算法验证平台**、**科研教学工具**或**中小规模定制项目的核心技术基座**。

**行业现状**: 截止2026年，大多数商业AGV调度系统仍处于**规则引擎+传统优化**阶段，RL主要在实验室阶段。AgvTms已实现**训练→保存→部署→评估**完整闭环。

#### 🔥 亮点4: 预测引擎三维度联动
```python

    def predict_task_load(self, horizon=3600) -> List[TaskPrediction]: ...
    def predict_congestion(self, zone_id) -> CongestionLevel: ...
    def predict_battery(self, agv_id, horizon=1800) -> BatteryForecast: ...
```
- **任务负载预测**: 基于历史模式的未来1小时任务量预估
- **拥堵预测**: 区域级别拥堵概率预测，提前绕行
- **电量预测**: 单车剩余工作时间预测，智能充电调度

**差异化**: 大多数商业系统的"预测"仅限于简单的规则外推，AgvTms采用多模型融合策略。

#### 🔥 亮点5: V2三层混合协调器的拉格朗日松弛
```
Layer 1 (Strategic)     →  MIP全局优化 [天/周]
        ↓ Lagrangian Relaxation (解耦)
Layer 2 (Tactical)      →  元启发式+规则分发 [分钟]
        ↓ Event-driven Replanning
Layer 3 (Operational)   →  A*+TW路径规划 [毫秒]

Rolling Horizon: 每10秒全量重规划
```
**技术创新**: 引入运筹学中的**拉格朗日松弛**技术解耦AGV子问题和输送线子问题，这在开源/学术系统中非常罕见。

### 5.2 AgvTms的独特优势功能

#### 🎯 独特优势1: 输送线任务排序优化 (NLP)

    目标函数: min(总完工时间 + 能耗)
    约束: 容量限制 + 任务优先级 + 无重叠
    求解器: scipy.optimize.minimize (SLSQP)
    """
    result = minimize(objective, x0, method='SLSQP', constraints=constraints)
    return result.x
```

**适用场景**: 混合型物流环境(AGV + 输送线), 如:
- 电商分拨中心的包裹流转线
- 制造业的产线物料配送
- 机场行李处理系统

**市场空白**: 这是AgvTms最显著的**差异化功能**, 商业产品中仅有博士(Bosch)输送线系统和罗克韦尔APS提供类似能力。

#### 🎯 独特优势2: 算法参数在线调优
```
前端 AlgorithmConfig 页面提供:
├── ACO参数: 蚁群数量(10-100), α(0.5-3), β(0.5-3), 蒸发率(0.1-0.9)
├── SA参数: 初始温度(100-1000), 冷却系数(0.9-0.99), 迭代次数(100-1000)
├── NLP参数: 权重系数(w_time, w_energy, w_priority)

**价值**: 无需修改代码即可针对不同场景调优算法行为，适合**快速POC验证**和**参数敏感性分析**。
