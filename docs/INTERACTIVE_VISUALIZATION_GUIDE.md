# AgvTms 交互式评测与调度可视化 - 功能指南

## 概述

本次迭代为算法评测系统新增了**三大核心能力**，让用户可以通过交互式界面灵活配置测试样本、注入故障场景，并实时可视化观察各算法的调度执行过程。

---

## 新增功能模块

### 1. 交互式样本配置器 (场景配置 Tab)

#### 1.1 双模式配置
- **预设模式**：选择8种预设场景模板（小型仓库/中型仓库/大型仓库/工厂/港口/医院/AGV+TMS混合/高压测试）
- **自定义模式**：完全参数化的场景生成

#### 1.2 可配置参数

| 类别 | 参数 | 范围 | 说明 |
|------|------|------|------|
| **基础** | 场景类型 | warehouse/factory/port/hospital/mixed | 决定地图布局和节点类型 |
| **基础** | 网格大小 | 5×5 ~ 50×60 | 地图规模 |
| **基础** | 难度 | easy/medium/hard/extreme | 影响AGV密度和任务复杂度 |
| **AGV** | 数量 | 1~100 | AGV车辆数量 |
| **AGV** | 速度范围 | 0.5~5.0 m/s | 每台AGV随机分配速度 |
| **AGV** | 电池范围 | 5%~100% | 初始电量区间 |
| **AGV** | 载重能力 | 0.5~2.0 | 单次搬运量 |
| **任务** | 数量 | 1~300 | 待搬运任务总数 |
| **任务** | 高优比例 | 0%~100% | 高优先级(P7/P9)任务占比 |
| **任务** | 时长范围 | 1~600s | 任务预计完成时间 |
| **TMS** | 输送线开关 | ON/OFF | 是否包含TMS输送系统 |
| **TMS** | 输送任务数 | 0~50 | TMS批量流转任务 |
| **TMS** | 线路段数 | 0~20 | 输送线路段数量 |
| **TMS** | 输送速度 | 0.1~3.0 m/s | 输送带运行速度 |

### 2. 故障模拟系统

#### 2.1 支持的故障类型

| 故障类型 | 说明 | 影响对象 | 可配参数 |
|----------|------|----------|----------|
| `agv_breakdown` | AGV故障停机 | 指定索引的AGV | 故障时刻、持续时长 |
| `conveyor_jam` | 输送线堵塞 | 指定线路段 | 堵塞时间、恢复时间 |
| `node_blocked` | 节点阻塞 | 指定节点ID | 阻塞时长 |
| `batch_fault` | 批量故障 | 同时影响AGV+输送线 | 综合配置 |

#### 2.2 故障参数配置
- **故障发生时间点**: 控制在仿真第几步时触发（默认50步）
- **持续时间**: 故障持续的仿真步数（默认30步）
- **影响目标**: 通过索引列表指定哪些AGV或线路段受影响

### 3. 实时调度可视化动画 (调度可视化 Tab)

#### 3.1 Canvas渲染元素
- **地图层**: 节点(按type着色)、边(灰色连线)、网格(可选)、输送线段(橙色矩形)
- **运动层**: AGV(圆形+方向箭头)、任务连线(虚线,按优先级着色)、路径轨迹(半透明)
- **事件层**: 故障标记(红圈闪烁+倒计时计时器)
- **信息面板**: 步骤/时间/完成率/活跃AGV数/平均电量等实时统计

#### 3.2 AGV状态颜色映射
| 状态 | 颜色 | 含义 |
|------|------|------|
| idle | 🟢 绿色 (#52c41a) | 空闲等待任务分配 |
| moving | 🔵 蓝色 (#1890ff) | 正在沿路径移动 |
| busy/executing | 🟡 黄色 (#faad14) | 取货/卸货中 |
| fault | 🔴 红色 (#ff4d4f) | 故障停机，闪烁警告 |
| charging | 🟣 紫色 (#722ed1) | 充电中 |

#### 3.3 动画控制功能
- ▶️/⏸ 播放暂停 / ⏮⏭ 上一步下一步 / ↺ 重置 / 进度条跳转
- 速度选择: 0.25x ~ 5x 变速播放
- 显示开关: AGV路径轨迹、任务起止连线
- 图例: 各状态颜色说明
- 当前事件提示: 底部显示最新事件描述

## 新增API端点

### `POST /api/v2/evaluator/scenarios/custom` - 自定义场景生成
完整的参数化场景生成，支持AGV/TMS/任务/故障全部可配。

### `POST /api/v2/evaluator/evaluate/visualize` - 带轨迹的可视化评估
返回标准评估报告 + 完整调度仿真轨迹数据(每步快照+事件序列)。

## 使用流程示例

### 示例1: 基础对比测试
1. 进入「场景配置」→ 预设模式 → 选择"中型仓库"
2. 全选6个算法 → 运行单场景评测
3. 查看「算法评测」Tab: 雷达图 + 排名表 + 维度分析

### 示例2: AGV故障鲁棒性验证
1. 自定义模式 → 仓库15×20, 15 AGV, 40 任务
2. 开启故障模拟: AGV故障, 故障AGV=[0,2], 第50步发生, 持续30步
3. 选择 fcfs 和 rl_dqn → 运行「可视化评测」
4. 观察动画中第50步后系统如何重新分配剩余任务

### 示例3: AGV+TMS混合压力测试
1. 自定义模式 → mixed类型, 启用输送线(15任务/6线路段)
2. 25 AGV, 60任务, 困难难度, 40%高优先级
3. 注入批量故障(同时AGV+输送线) → 运行可视化
4. 对比各算法在复杂混合场景下的表现差异
