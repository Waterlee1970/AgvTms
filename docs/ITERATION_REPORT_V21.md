## 二、关键发现与分析

### 1. 算法特性分化明显

分层特征:
- **第一梯队** (fcfs/greedy): 效率+实时双优，适合在线调度
- **第二梯队** (rl_dqn): 均衡发展，学习型潜力大
- **第三梯队** (v1_hybrid): 质量维度独占鳌头(100分)，适合离线规划
- **第四梯队** (v2_mip/orchestrator): 需要进一步优化参数或场景适配

### 2. AG+TMS混合场景表现

- fcfs 在混合场景中得分最高 (86.7分)，证明简单策略在复杂场景中的稳定性
- rl_dqn 紧随其后 (86.6分)，强化学习展现出良好的泛化能力
- 输送线协同对所有算法的影响较为均匀，未造成显著差异

### 3. 规模扩展性

| 场景规模 | fcfs | rl_dqn | v1_hybrid | 变化趋势 |
|----------|:----:|:------:|:----------:|----------|
| 小型(5AGV/15任务) | 85.0 | 76.0 | 64.7 | 基准 |
| 中型(15AGV/40任务) | 85.4 | 84.8 | 64.9 | RL大幅提升 |
| 大型(20AGV/50任务) | 86.3 | 86.0 | 58.8 | Hybrid下降 |
| 极限(50AGV/150任务) | 86.6 | 85.2 | 58.8 | 稳定 |

结论: FCFS/Greedy具有极好的规模不变性；RL-DQN在中等规模以上表现优异；V1Hybrid在大规模场景中需要优化。

## 三、评分体系验证

当前5维权重配置:
```python
weights = {
    'efficiency': 0.35,
    'quality': 0.25,
    'resource': 0.20,
    'realtime': 0.15,
    'robustness': 0.05,
}
```

归一化参考范围:
- makespan: 最优<60s, 最差>3600s
- completion_rate: 100%=满分, 0%=零分
- total_distance: <10m=满分, >5000m=零分
- collision_rate: 0%=满分, >5%扣分严重
- compute_time_ms: <10ms满分, >5000ms零分
